## Responsibilities

- Review pull requests
- Triage issues
- Manage releases
- Update documentation
- Ensure Billions TEE compliance
- Monitor security

## How to Become a Maintainer

1. Contribute quality pull requests
2. Help review others' PRs
3. Actively participate in discussions
4. Be nominated by existing maintainers

## Maintainer Guidelines

- Be responsive (respond within 48 hours)
- Follow code of conduct
- Document major changes
- Test before merging
- Keep game fun and educational

## Release Process

1. Update [CHANGELOG.md](CHANGELOG.md)
2. Update version in [VERSION.md](VERSION.md)
3. Create release tag
4. Deploy to Vercel
5. Announce on Discussions
