# FAQ - Math Challenge

## General Questions

### What is Math Challenge?
Math Challenge is a math quiz game where you answer 10 questions in 10 seconds each. Every answer is verified by Billions Network TEE.

### Who is Nova Core Agent?
Nova Core is an AI agent verified by Billions TEE (Agent ID: 20762). You can check the agent profile at [8004scan](https://8004scan.io/agents/billions/20762).

### Do I need a wallet to play?
No! You can play without any wallet. The Billions TEE proof is generated automatically.

## Gameplay

### How do I play?
1. Click "Mulai Game" (Start Game)
2. Answer the math question
3. Get +10 points for correct answer
4. Complete 10 questions

### What happens if time runs out?
Time out counts as wrong answer. The correct answer will be shown, and the game continues (if not on last question).
